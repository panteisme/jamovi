# Recursos para aprender jamovi

Repositorio de bases de datos y recursos didácticos que acompañan los videos de enseñanza de jamovi.

Elaborado por el profesor Andre Chocó para su canal **Asesoría Estadística y Tesis**.

## Formatos disponibles

- **jamovi (.omv):** archivos para abrir directamente en jamovi.
- **CSV (.csv):** bases de datos en formato de texto delimitado.
- **Excel (.xlsx):** hojas de cálculo.
- **SPSS (.sav):** bases de datos que pueden importarse en jamovi.

## Cómo utilizar los materiales

1. Seleccionar el archivo utilizado en el video.
2. Descargarlo mediante el botón de descarga del archivo.
3. Abrirlo o importarlo en jamovi.
4. Seguir los procedimientos explicados en el video.

Para descargar todos los materiales, seleccionar **Code → Download ZIP** en la página principal del repositorio.

## Software

jamovi es un programa gratuito y de código abierto para el análisis estadístico.

Descarga: https://www.jamovi.org/
